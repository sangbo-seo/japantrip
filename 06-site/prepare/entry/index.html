입국·세관

개요

한국 국적 일반여권으로 관광, 친지 방문, 견학처럼 90일 이내로 머무는 여행이라면 비자 없이 입국할 수 있습니다. 보수를 받는 활동은 이 면제 대상이 아닙니다 (주한 일본대사관). 입국 서류는 Visit Japan Web 으로 미리 등록해 두고, 공항에서는 QR 만 보여 주는 방식이 가장 빠릅니다 (일본 세관, Visit Japan Web 이용 안내). 가족 여행이라면 출발 일주일 전쯤 여권 정보부터 한 번에 입력해 두면 마음이 편합니다. 이 시점은 공식 기한이 아니라 이 사이트의 권장입니다.

무비자 체류 90일

항목내용출처
대상일반여권을 가진 한국인이 90일 이내 단기 체재 목적으로 입국할 때주한 일본대사관
가능한 목적관광, 오락, 지인과 친족 방문, 견학과 시찰, 단기 상용 등주한 일본대사관
제외사업을 운영하거나 보수를 받는 활동주한 일본대사관
90일을 넘길 때비자 등 별도 체류자격 절차가 필요합니다. 세부 요건은 확인 필요주한 일본대사관
전자 사전 허가 제도일본 정부 성장전략(2026)은 JESTA 를 2028 회계연도 중 도입한다고 적고 있어 현재는 시행 전입니다. 정확한 시행일과 신청 방법은 확인하지 못했으니 출발 전에 일본 정부 공식 안내를 다시 보세요일본 정부 성장전략

Visit Japan Web 등록 순서

  1. 계정을 만듭니다. 새 계정에는 이메일 주소가 필요합니다 (Visit Japan Web 이용 안내).
  2. 이용자 정보를 등록합니다. 입국 수속 구분을 고르고 여권 정보를 넣습니다. 방법은 카메라로 읽기와 직접 입력 중 선택하며, 카메라 인식이 계속 실패하면 직접 입력으로 바꿀 수 있습니다 (Visit Japan Web 이용 안내).
  3. 여권 남은 유효기간이 6개월 미만이면 경고 문구가 뜹니다. 가족 모두의 여권 만료일을 먼저 확인하세요 (Visit Japan Web 이용 안내).
  4. 직업, 주소 같은 기본 정보와 일본 내 연락처(숙소)는 선택 입력입니다. 미리 넣어 두면 다음 단계에서 다시 입력하지 않아도 됩니다 (Visit Japan Web 이용 안내).
  5. 입국 예정을 등록합니다. 여행 정보를 넣고 일정을 저장합니다 (Visit Japan Web 이용 안내).
  6. 등록한 일정을 눌러 검역(건강 상태 확인)과 입국심사 및 세관신고 항목을 입력합니다 (Visit Japan Web 이용 안내).
  7. 수속 화면에서 QR 을 띄웁니다. 입국심사에서는 입국심사 카운터에서, 세관신고에서는 전자신고 단말기나 검사대에서 사용합니다. 전자신고 단말기로 신고하면 전자신고 게이트로 나갈 수 있습니다 (Visit Japan Web 이용 안내).
  8. 하네다, 후쿠오카, 나하 공항에서는 맡긴 짐이 나오기를 기다리는 동안 전자신고 단말기로 세관신고를 할 수 있습니다 (Visit Japan Web 이용 안내).
  9. Visit Japan Web 은 오프라인에서도 쓸 수 있는 기능이 있습니다. 로그인 화면의 오프라인 이용 안내를 출발 전에 한 번 확인해 두세요 (Visit Japan Web 조작설명서).

동반 가족(아이 포함)은 Visit Japan Web 에서 한 사람씩 등록합니다. 홈 화면의 동반 가족 항목에서 추가하며 최대 10명까지 등록할 수 있고, 입국·귀국 수속은 한 사람씩 처리됩니다 (Visit Japan Web 조작설명서).

세관 신고와 면세 범위

입국하는 모든 사람은 소지품을 신고해야 하고, 일본 세관은 Visit Japan Web 을 통한 전자신고를 권장합니다. 초록 통로는 세금 낼 물건과 금지·제한 물품이 없는 사람, 빨간 통로는 그 밖의 사람이 이용합니다 (일본 세관). 아래는 반입 물품의 관세 면세 범위이며, 쇼핑 면세 환급과는 다른 제도입니다. 환급은 현장 > 쇼핑·면세 글을 보세요.

품목성인 1인 면세 범위출처
술3병 (1병은 약 760cc 기준)일본 세관
담배궐련 200개비, 여러 종류를 섞으면 합계 250g 상당일본 세관
향수2온스 (1온스는 약 28ml)일본 세관
그 밖의 물품해외 시가 합계 20만엔 이하. 1만엔 미만 품목은 합계에서 제외, 한 개 또는 한 세트가 20만엔을 넘으면 면세 범위 없음일본 세관
현금과 유가증권합계 100만엔 초과 시 세관에 신고일본 세관

반입 금지·제한 물품

  • 금지: 마약류, 총기류와 실탄, 폭발물, 위조 화폐와 위조 카드, 공공 안전과 풍속을 해치는 서적과 영상, 지적재산권을 침해하는 물품 (일본 세관).
  • 제한: 동식물은 검역을 먼저 받아야 합니다. 의약품과 화장품은 수량 제한이 있고, 사냥총, 공기총, 도검류는 허가 없이 반입할 수 없습니다 (일본 세관).
  • 식품: 일본 세관의 관련 법령 표에서 음식물 전반은 식품위생법, 육류와 소시지, 햄 등은 가축전염병예방법, 쌀과 떡 등 곡물 제품은 주식 수급 안정법의 대상입니다. 선물용 한국 음식 중 육류 제품(소시지, 햄, 육포 포함)은 수출국 정부의 검사증명서가 없으면 소량이나 선물이어도 반입할 수 없고, 도착하면 동물검역소 카운터에서 검사를 받아야 합니다 (농림수산성 동물검역소). 과일, 채소 같은 식물류도 식물방역소 검역 대상입니다 (농림수산성 식물방역소). 그 밖의 품목은 각 검역소에 문의하세요.
  • 의약품 (후생노동성): 처방약, 독극물은 1개월분 이내, 그 밖의 일반 의약품과 의약외품은 2개월분 이내, 외용약은 품목당 24개 이내면 수입 확인 신청이 필요 없습니다. 일회용 콘택트렌즈는 2개월분 이내입니다. 지정된 성분이 든 제품은 반입이 제한되고, 마약과 각성제 원료 성분 약은 사전 허가가 필요합니다. 지정 성분 목록은 후생노동성이 영문 표로 공개하고 있으니 가져갈 약의 성분을 대조하세요 (후생노동성). 허가 절차는 대사관 안내 (주한 일본대사관)를 보세요.
  • 화장품은 품목당 24개 이내까지 별도 신청이 필요 없습니다 (후생노동성).

자주 하는 실수

  • 여권 정보를 카메라로 읽다 계속 실패하는데 같은 방법만 반복합니다. 직접 입력으로 바꾸세요.
  • 가족 중 한 명만 여권 남은 기간이 6개월 미만인 것을 도착 직전에야 알게 됩니다.
  • 반입 물품 합계를 계산할 때 한 개가 20만엔을 넘는 물건은 면세 범위가 아예 없다는 점을 놓칩니다.
  • 상비약을 넉넉히 챙기다 수량 기준을 넘깁니다. 가족 약은 사람별로 나누어 계산하세요.
  • 무비자를 근거로 현지에서 보수를 받는 일을 하면 면제 목적에서 벗어납니다.
