출발 전 타임라인

개요

출발 전 할 일을 D-60, D-30, D-7, D-3, 당일로 나눈 요약 허브입니다. 항목별 상세 체크박스는 출국 전 체크리스트에 있고, 이 페이지는 시점별로 무엇을 해야 하는지 한눈에 보게 하는 용도입니다. 아래 시점은 공식 기한이 아니라 이 사이트의 권장 일정입니다. 공식 기한이나 규정이 확인된 항목에만 출처를 달았습니다.

시점별 요약

시점핵심 할 일자세히 보기
D-60여권 만료일 확인, 90일 이내 체류 확인, 항공권과 숙소 예약, 총액 예산항공권 총액 비교, 입국·세관
D-30통신 방식 결정, 카드 해외결제 설정 확인, 약 수량 확인, Visit Japan Web 계정 만들기통신, 돈·결제, 짐·준비물
D-7Visit Japan Web 등록과 QR 확인, 환전, 짐 싸기, 변환 플러그입국·세관, 짐·준비물
D-3로그인 재확인, 오프라인 대비, 숙소 주소 저장, 충전현장 > 문제 대응 > 데이터가 안 될 때 대처법
당일서류 위치 확인, 가족 수만큼 여권 세기, 입국 흐름 기억출국 전 체크리스트

시점별 포인트

D-60

  1. 가족 전원의 여권 만료일을 확인합니다. Visit Japan Web 은 여권 남은 유효기간이 6개월 미만이면 경고를 표시합니다 (Visit Japan Web 이용 안내). 주한 일본대사관은 입국에 유효한 여권이 필요하지만 남은 유효기간에 구체적인 제한은 없고, 유효기간이 충분한 여권을 권한다고 안내합니다 (주한 일본대사관). 항공사별 기준은 이용 항공사 안내에서 확인하세요.
  2. 90일 이내 관광 체류는 비자가 필요 없습니다 (주한 일본대사관).
  3. 항공권은 세금과 부가 요금을 더한 총액으로 비교합니다. 일본 출국세는 2026-07-01 이후 출국 1회당 3,000엔입니다 (일본 국세청).

D-30

  1. 로밍, eSIM, 유심, 포켓와이파이 중 가족에게 맞는 방식을 정합니다. 요금은 확인 필요.
  2. 카드의 해외 이용 설정과 수수료, 원화 결제 차단 여부를 확인합니다.
  3. 복용 약의 수량이 후생노동성 기준 안인지 확인합니다 (후생노동성).
  4. Visit Japan Web 계정을 만듭니다. 이메일 주소가 필요합니다 (Visit Japan Web 이용 안내).

D-7

  1. Visit Japan Web 에 이용자 정보, 입국 예정, 입국심사 및 세관신고를 입력하고 QR 이 뜨는지 확인합니다 (Visit Japan Web 이용 안내).
  2. 환전과 현금 배분을 정합니다. 숙박세 같은 현지 지불 비용도 미리 계산합니다.
  3. 변환 플러그와 충전기를 챙깁니다. 일본은 100볼트, A형 콘센트입니다 (JNTO).
  4. eSIM 은 설치 방식과 시점을 판매처 안내로 확인합니다.

D-3

  1. Visit Japan Web 에 다시 로그인해 등록 내용을 확인합니다. 오프라인 이용 기능이 있으니 안내를 한 번 확인해 둡니다 (Visit Japan Web 조작설명서).
  2. 숙소 이름, 주소, 전화번호를 스크린샷으로 저장합니다.
  3. 지도와 번역 데이터를 내려받고 보조 배터리와 휴대폰을 충전합니다.

당일

  1. 여권, 항공권, 입국 QR, 숙소 정보를 가방 맨 위에 둡니다.
  2. 가족 수만큼 여권이 있는지 셉니다.
  3. 도착 후 입국심사와 세관에서 QR 을 보여 줍니다 (Visit Japan Web 이용 안내).

자주 하는 실수

  • 출발 직전에야 Visit Japan Web 을 시작해 여권 오류를 만났을 때 시간이 없습니다.
  • 가족 중 한 명의 여권 만료일 확인을 빠뜨립니다.
  • eSIM 을 도착 후 설치하려다 연결이 안 됩니다.
  • 항공권 총액에서 일본 출국세 포함 여부를 보지 않습니다.
  • 공항에서 휴대폰 배터리가 부족한데 충전기를 위탁 가방에 넣어 둡니다.
