예산 계산기

가족 여행 총예산을 항목별로 쌓아 계산하는 시트입니다. 값은 직접 넣는 칸이고, 이 사이트의 일정 글에서 확인된 기준값을 참고용으로 붙였습니다. 기준일 2026-10-22.

1. 계산식

총예산 = 항공 + 숙박 + 식비 + 시내 교통 + 입장료·체험 + 통신 + 쇼핑 + 예비비

엔화 항목은 먼저 엔으로 합산한 뒤 한 번만 원화로 바꿉니다. 항목마다 환산하면 반올림 오차가 쌓입니다.

원화 환산 = 엔 합계 x 적용 환율 (100엔당 원화 / 100)

2. 입력표 (가족 3인 기준 예시 틀)

항목계산 방법입력참고할 글
항공1인 왕복 운임 x 인원 + 수하물 + 좌석 + 수수료원항공권 총액 비교
숙박1박 요금 x 박수 (방 개수 확인)엔도시 허브 F 블록
식비1인 1일 식비 x 인원 x 일수엔도시 허브 I 블록
시내 교통일정 글 교통 행엔일정 글, 이동 메뉴
공항 이동편도 요금 x 인원 x 2엔공항에서 시내 글
입장료·체험시설별 어른/어린이 요금 합엔일정 글 총비용 표
통신eSIM 또는 로밍원통신 허브
쇼핑면세 기준 5,000엔(세전) 단위 확인엔면세 환급 글
예비비합계의 10% 안팎엔개인 판단

3. 기준값 (이 사이트 글에서 확인된 것)

아래 값은 글마다 계산 범위가 달라 그대로 비교할 수 없습니다. 비교 전에 범위 열을 꼭 보세요.

일정 글표기된 예상 비용계산 범위
후쿠오카 2박 3일1인 약 35~65만원 (가족 3인 합계 약 106~194만원)항공, 숙박, 식비, 교통, 입장료 포함
후쿠오카 3박 4일1인 약 43~78만원같음
후쿠오카 4박 5일1인 약 50~92만원같음
오사카 2박 3일, 3박 4일1인 약 32만~62만원숙박과 식비 제외, 항공 포함
오사카 4박 5일1인 약 33만~64만원숙박과 식비 제외
도쿄 3박 4일항공 제외 3인 약 104~193만원숙박, 식비는 가정치

숙박과 식비가 빠진 값에는 직접 더해야 합니다. 후쿠오카 글은 숙박 1박 약 7~18만원, 식비 1인 1일 3,500~5,500엔을 가정치로 썼습니다. 이 가정치도 출처가 있는 값이 아니므로 예약 사이트에서 실제 가격으로 바꿔 넣으세요.

4. 계산 예시 (형식 확인용)

후쿠오카 2박 3일 글의 교통 행처럼, 어른 요금으로 어린이까지 계산하면 상한이 되고 실제 합계는 낮아질 수 있습니다. 어린이 요금이 확인된 항목은 어린이 요금으로 바꿔 넣으면 정확해집니다.

단계값
엔 합계직접 입력
환율100엔당 원화 직접 입력
원화 환산엔 합계 x 환율 / 100
항공과 통신 (원화)직접 입력
총예산원화 환산 + 항공 + 통신
1인당총예산 / 인원

5. 체크

  • 위탁수하물, 좌석 지정, 카드 수수료를 항공 항목에 넣었는가
  • 숙박세를 숙박 항목에 넣었는가 (도시마다 다름)
  • 아이 요금과 어른 요금을 구분했는가
  • 환율이 오늘 기준인가, 카드 해외결제 수수료를 반영했는가
  • 예비비를 남겼는가

관련 글: 항공권 총액 비교, 환율 메모, 일정 비교표
