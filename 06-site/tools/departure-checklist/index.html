출국 체크리스트

개요

인쇄하거나 휴대폰에 저장해 쓰는 한 장짜리 요약 체크리스트입니다. 항목마다 근거와 설명이 붙은 상세판은 출발 전 체크리스트 상세에 있습니다. 이 페이지의 항목은 상세판과 허브 글의 내용을 줄인 것이며, 기한은 공식 기한이 아니라 이 사이트의 권장 시점입니다. 여행 인원이 여럿이면 사람 수만큼 인쇄해 각자 체크하면 편합니다.

인쇄용 체크리스트

D-60

  • [ ] 가족 전원 여권 만료일 확인
  • [ ] 체류 일수 90일 이내 확인
  • [ ] 항공권 예약 (세금과 부가 요금을 더한 총액으로 비교)
  • [ ] 숙소 예약과 취소 규정 저장
  • [ ] 총예산 정하기

D-30

  • [ ] 통신 방식 정하기 (로밍, eSIM, 유심, 포켓와이파이)
  • [ ] 휴대폰의 eSIM 지원과 통신사 잠금 해제 여부 확인
  • [ ] 카드 해외 이용 설정과 원화 결제 차단 확인
  • [ ] 복용 약 수량 확인 (일반 의약품 2개월분, 처방약 1개월분 이내가 신청 없이 가능한 기준)
  • [ ] Visit Japan Web 계정 만들기

D-7

  • [ ] Visit Japan Web 에 여권 정보, 입국 예정, 입국심사 및 세관신고 입력
  • [ ] QR 이 뜨는지 확인
  • [ ] 환전과 현금 배분
  • [ ] 변환 플러그와 충전기 챙기기 (일본은 100볼트, A형 콘센트)
  • [ ] eSIM 설치 시점 확인
  • [ ] 짐 싸기, 가족별 약 나누기

D-3

  • [ ] Visit Japan Web 다시 로그인해 확인
  • [ ] 숙소 이름, 주소, 전화번호 저장
  • [ ] 지도와 번역 데이터 내려받기
  • [ ] 휴대폰과 보조 배터리 충전

당일

  • [ ] 여권, 항공권, 입국 QR, 숙소 정보
  • [ ] 가족 수만큼 여권 세기
  • [ ] 현금, 카드, 변환 플러그, 충전기, 먹는 약을 기내 가방에
  • [ ] 입국 후 순서 기억: 입국심사, 짐 찾기, 세관

이 도구 쓰는 법

  1. 인쇄할 때는 이 페이지를 용지 한 장에 맞춰 출력합니다.
  2. 휴대폰에 저장할 때는 화면을 캡처해 두고, 체크한 항목은 따로 표시합니다.
  3. 가족 구성에 따라 항목을 더하거나 빼세요. 아이 동반과 부모님 동반 항목은 짐·준비물을 참고합니다.
  4. 출발 직전에는 상세판의 D-3과 당일 항목을 한 번 더 읽습니다.

자주 하는 실수

  • 인쇄만 하고 출발 직전에 훑어봅니다. 시점별로 나누어 확인하세요.
  • 사람 수만큼 쓰지 않고 한 장으로 가족 전체를 관리해 빠지는 항목이 생깁니다.
  • 체크리스트의 규정 항목을 그대로 믿고 최신 공식 안내를 확인하지 않습니다. 규정은 바뀔 수 있습니다.
