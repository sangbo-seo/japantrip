# 도시 허브 본문 재작성 지침 (2026-10-22 기준)

대상: 03-content\02-regions\<권역>\<도시>\index.md 16곳 중 지정된 2곳.
목표: 본문(A~P 블록)을 처음부터 다시 쓰되, 앞머리(front matter) 필드 이름과 기존 확인 값은 유지하고 아래 보정 사항을 반드시 반영합니다.

## 절차
1. 대상 파일을 읽고 현재 앞머리, A~P 구조, 확인 필요 목록을 파악합니다.
2. 같은 권역의 권역 페이지(03-content\02-regions\<권역>\_index.md)와 다른 도시 허브를 읽고 값이 어긋나지 않게 맞춥니다.
3. 아래 보정 사항을 본문에 반영합니다. 원본이 틀렸으면 고치고 '정정'이라고 짧게 적습니다.
4. 웹 조사로 공식 출처를 다시 확인할 수 있는 항목만 새로 확인합니다. 확인 못 하면 '확인 필요'로 남깁니다. 지어내지 않습니다.
5. 본문을 repl에서 fs.writeFile 로 전체 교체합니다(앞머리 포함). 한국어 문자열 편집에 edit_file을 쓰지 않습니다.

## 보정 사항 (반드시 반영)
- 간토 권역 출처: 도쿄~요코하마 약 30분은 역탐(비공식, JR 약 27분) 기준입니다. 카메라 관광협회 안내의 30분은 요코하마~가마쿠라 시간이므로 출처로 쓰지 않습니다.
- 오키나와: 슈리성 화재는 2019년 10월 31일입니다. 2024년이 아닙니다. 재건 개관 2026-11-23, 입장료는 개관 후 어른 1,000엔입니다.
- 고베: 오지동물원 팬더 탄탄은 2024년 3월 폐사했습니다. 현재 판다가 없습니다.
- 마쓰야마: 공항 출발 막차 21:35는 10월 25일~11월 30일 시간표입니다. 10월 1~24일은 21:30이었습니다. 도고온천 전차 소요는 공식 약 20~25분입니다(10분은 비공식).
- 마쓰야마: 우치코자 극장은 2024년 9월부터 개보수 휴관, 2029년 봄 재개관 예정입니다.
- 도쿄: N'EX는 2026-11-06 저녁~11-08 오전 일부가 영향을 받고, 11-07은 도쿄~시나가와 구간 운행 중단입니다.
- 요코하마: 랜드마크 타워 69층 전망대는 2025-12-31부터 대규모 수리로 휴관, 2028년 이후 재개입니다.
- 삿포로: 시키사이노오카는 비에이 근교입니다. 시내 명소로 쓰지 않습니다.
- 다카마쓰: 해변·곶은 다케이간논미사키(차량), 메기지마 유미가하마(페리 20분, 370엔), 오기지마 해수욕장(페리 40분, 510엔)입니다. '우도노 해수욕장'은 공식 명소에서 확인되지 않았으니 쓰지 않습니다.
- 나고야: 나고야성 천수각 내부는 2018년부터 폐관, 관람료는 2026-10-01부터 성인 1,000엔입니다. 나고야역행 리무진은 운휴 중입니다.
- 교토: 교토시에는 공항이 없습니다. 간사이공항 하루카 약 75분, 리무진 2,800엔, 이타미 리무진 1,500엔입니다.
- 나라: 도다이지 대불전은 어른 800엔, 현금만 결제입니다. 나라국립박물관 불상관은 2026-09-14부터 2028년 봄까지 공사 휴관입니다.

## 작성 규칙
- 한국어, 가족(성인 2 + 초등 1) 시점, 표와 번호 목록 사용. 이모지 금지. 한자(漢字)와 영어 단어는 고유명사와 약어 외에는 쓰지 않으며, 지명 한자 표기도 쓰지 않습니다(한국어·로마자 표기만).
- 직항 여부, 요금, 시간, 휴관, 예약 규정은 출처 이름을 괄호로 답니다. 비공식 값은 '비공식'이라고 표시합니다.
- 환율은 기준일과 값을 밝히고 원화는 '약'.
- 글자 수 목표는 9,000~14,000자입니다.

## 저장과 검사
- U+FFFD 0개, 한자(\u4E00-\u9FFF) 0개, 앞머리 정상 닫힘, 상대 .md 링크가 실제 파일을 가리키는지 확인합니다.
- 지정된 파일만 수정합니다.
