# 공식 자료 확인 작업 지침 ('확인 필요' 채우기)

기준일: 2026-10-22. 이미 작성된 글에서 '확인 필요'로 남은 항목을 공식 자료로 확인해 채우는 작업입니다.

## 할 일
1. 작업 지시에 적힌 파일들을 읽고 '확인 필요' 문구가 있는 줄을 모두 목록으로 만듭니다(본문과 마지막 '확인 필요 항목' 섹션 모두).
2. 항목마다 공식 또는 신뢰 가능한 1차 출처(철도, 공항, 시설, 지자체, 항공사, 정부 기관 공식 사이트)를 WebSearch/WebFetch로 확인합니다. 공식 사이트가 열리지 않으면 영어/일본어 공식 페이지, 공식 PDF, 공식 SNS 공지를 시도합니다. 그래도 안 되면 그 항목은 '확인 필요'로 그대로 둡니다. 지어내거나 비공식 값으로 단정하지 않습니다.
3. 확인되면 본문의 '확인 필요' 자리에 값을 넣고 출처 이름을 괄호로 답니다. 앞머리 sources 에 URL을 추가하고, update_note 에 '2026-10-22 공식 확인 N건 반영'을 덧붙입니다.
4. 이미 적힌 비공식 값(블로그, 민간 안내)이 공식 값과 다르면 공식 값으로 고치고 본문에 정정 사실을 적습니다. 허브와 하위 글 사이의 값이 서로 다르면 맞춥니다.
5. 값이 바뀌어 총비용 표, est_cost, cost_basis, 합계가 달라지면 같은 파일 안에서 다시 계산해 맞춥니다. 원화 환산은 기존 환율 기준을 그대로 씁니다.
6. 마지막 '확인 필요 항목' 섹션에서 해결된 항목은 지우고, 남은 항목에는 시도한 출처와 실패 이유(접속 불가, 정보 없음)를 한 줄로 덧붙입니다.

## 규칙
- 수정은 필요한 줄만. 구조, 제목, 앞머리 필드 이름, 다른 내용은 건드리지 않습니다.
- 한국어 문자열 편집은 edit_file 이 불안정하니, repl 에서 fs.readFile 로 읽고 JS 문자열 치환(split/join)으로 바꾼 뒤 fs.writeFile 로 전체를 다시 씁니다. 치환 대상 문자열은 파일에서 읽은 줄을 그대로 코드로 추출해 쓰고, 손으로 다시 타이핑하지 않습니다.
- 저장 후 파일을 다시 읽어 U+FFFD 0개, 한자(\u4E00-\u9FFF) 0개, 앞머리 정상 닫힘을 검사하고, 수정 전 내용과 줄 단위로 비교해 의도하지 않은 줄이 바뀌지 않았는지 확인합니다.
- 이모지 금지. 한자와 영어 단어는 고유명사와 약어 외에는 쓰지 않습니다.
- 지정된 파일 외에는 수정하지 않습니다.

## 보고
마지막 답변에 (a) 파일별 해결한 항목 수와 핵심 값 변화(이전 값, 새 값, 출처), (b) 끝내 확인하지 못한 항목 목록과 이유, (c) 총액을 다시 계산한 곳을 간단히 적습니다.
