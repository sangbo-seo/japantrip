# 권역 페이지 작성 지침 (일본여행정보 사이트)

기준일: 2026-10-22. 대상: 한국인 가족(성인 2명 + 초등 자녀 1명)·가성비 여행자.
권역 페이지는 도시 허브 위의 허브입니다. "이 권역에서 어떤 도시를 어떻게 묶어 갈지"를 정하게 돕는 글입니다.

## 파일
- 대상 파일은 작업 지시에 있습니다(03-content\02-regions\<권역>\_index.md). 먼저 그 파일, 그 권역 도시 허브(index.md), 권역 안의 일정·이동 글, 02-templates\writing-brief.md, 00-docs\도시페이지_와이어프레임.md 를 읽습니다.
- 앞머리(front matter)의 title, slug, menu, url 은 유지하고 description, summary, last_checked: 2026-10-22, published: 2026-10-22, status: 검수, sources(URL 목록), update_note, thumbnail(/img/<slug>-region.jpg 자리표시), thumbnail_alt 를 채웁니다.
- 기존 본문의 '도시 비교' 표와 '이 권역의 글' 목록, '앞으로 추가할 도시' 절은 유지하되 최신 내용으로 다듬고 그 위아래에 아래 절을 추가합니다. 기존 표의 값은 도시 허브와 일치해야 합니다.

## 본문 구조 (순서 유지)
1. 권역 한눈에 보기: 한 줄 요약, 이 권역이 맞는 사람/덜 맞는 사람, 추천 체류 일수
2. 도시 비교 (기존 표 유지)
3. 도시 고르는 법: 상황별(일수, 아이 나이, 이동 부담, 예산, 계절) 추천을 표로
4. 권역 안 이동: 도시 간 교통 수단 비교표(소요시간, 요금, 어린이 요금, 예약 필요). 공식 출처로 확인된 값만. 확인 못 하면 '확인 필요'
5. 추천 조합 루트 2~3개(예: 도시 2곳 묶기). 일수 배분, 이동일 처리, 아이 피로 고려
6. 시즌 가이드: 월별 또는 계절별 특징(공식 관광 사이트 또는 기상청 자료로 확인된 범위. 수치가 없으면 서술만)
7. 권역 공통 주의: 휴관·공사·재해 현황·예약 필요 시설·기타 변동 사항(현재 상황을 공식 자료로 확인)
8. 이 권역의 글 (기존 목록 유지, 추가된 글이 있으면 반영)
9. FAQ 5~7개
10. 앞으로 추가할 도시 (이름만, 사실 단정 없이)
11. 확인 필요 항목, 공식 출처

## 조사·작성 규칙
- WebSearch/WebFetch로 공식 또는 신뢰 가능한 1차 출처(철도, 공항, 지자체, 관광청 JNTO, 시설 공식)를 확인합니다. 열리지 않으면 영어/일본어 공식 페이지를 시도하고, 그래도 안 되면 '확인 필요'로 남기며 이유를 한 줄 적습니다. 비공식 값은 본문에 '비공식'을 표시합니다.
- 요금·소요시간·운영시간은 확인된 것만 쓰고 출처 이름을 괄호로 답니다. 도시 허브·일정 글에 이미 있는 공식 확인 값은 재사용하되 모순 없게 합니다.
- 환율은 기준일과 값을 밝히고 원화는 '약'. 기존 글과 같은 기준을 씁니다.
- 한국어, 가족 시점, 표와 번호 목록 적극 사용. 이모지 금지. 한자와 영어 단어는 고유명사와 약어(JR, IC 등) 외에는 쓰지 않습니다.

## 저장과 검사
- 기존 파일을 repl에서 Node fs.writeFile 로 전체를 한 번에 씁니다(한국어 문자열 편집에 edit_file 을 쓰지 않습니다). 쓰기 전에 기존 파일 내용을 읽어 보존할 부분(앞머리 일부 필드, 도시 비교 표, 글 목록 링크)을 코드로 추출해 다시 씁니다.
- 저장 후 다시 읽어 U+FFFD 0개, 한자(\u4E00-\u9FFF) 0개, 앞머리 정상 닫힘, 모든 상대 링크(.md)가 실제 파일을 가리키는지 검사합니다.
- 지정된 파일만 수정합니다.
