# 글 작성 지침 (일본여행정보 사이트)

기준일: 2026-10-22. 대상: 한국인 가족·가성비 여행자.

## 파일 만들기
- 새 파일을 만듭니다. 위치와 파일명은 작업 지시에 있습니다. 02-templates 의 알맞은 템플릿(post-itinerary / post-transport / post-basic)을 먼저 읽고 앞머리(front matter) 필드와 본문 구조를 그대로 따릅니다.
- 앞머리 필수 필드를 모두 채웁니다: id, type, title, summary(60자 이내), menu, region, duration, companions, kid_fit, reservation, est_cost, cost_basis, read_time, rain_ok, themes, season, last_checked: 2026-10-22, published: 2026-10-22, status: 검수, thumbnail(/img/<id>.jpg 자리표시), thumbnail_alt, slug, hub, related_posts, next_step, sources(URL 목록), update_note. 해당 없으면 '해당없음'.
- 같은 지역 허브 파일(03-content\02-regions\...\index.md)을 먼저 읽고, 이미 조사해 둔 사실과 출처를 재사용하되 서로 모순되지 않게 합니다. 허브에 '확인 필요'로 남은 수치는 이번에 공식 자료로 확인해 보고, 확인되면 쓰고 안 되면 '확인 필요'로 남깁니다.
- 허브 파일과 다른 글은 수정하지 않습니다. 새 파일 1~2개만 만듭니다.

## 조사 규칙
- WebSearch/WebFetch로 공식 또는 신뢰 가능한 출처(철도·공항·시설·지자체·항공사 공식 사이트, JNTO)를 확인합니다. 공식 사이트가 열리지 않으면 민간 안내를 쓰되 본문에 출처 이름과 '비공식'을 표시합니다.
- 요금, 소요시간, 운영시간, 예약 규정, 휴관일은 출처에서 확인된 것만 적고 출처 이름을 괄호로 답니다. 확인 못 하면 지어내지 말고 '확인 필요'로 적습니다.
- 환율은 기준일과 값을 명시하고 원화 환산은 '약'으로 씁니다. 항공 가격은 단정하지 말고 범위와 확인 방법만 씁니다. 숙박·식비는 출처가 없으면 가정치임을 밝힙니다.
- 인터넷 문장을 그대로 옮기지 말고 직접 요약해 씁니다.

## 작성 규칙
- 한국어, 가족(성인 2명 + 초등 자녀 1명) 시점. 구체적이고 실용적으로, 표와 번호 목록을 적극 사용합니다.
- 일정 글: 하루 방문지 2~3곳, 오후 휴식 지점, 예약 필수 시설, 총비용 표(항목, 금액, 기준), 귀국 동선, 비 오는 날 대안.
- 이모지 금지. 한자(漢字)와 영어 단어는 고유명사와 약어(JR, IC, ETC, eSIM 등) 외에는 쓰지 않습니다.
- 본문 끝에 '확인 필요 항목'과 '공식 출처' 목록을 둡니다.

## 저장과 검사
- write_file 은 기존 파일을 덮어쓰지 못하니 repl 에서 Node fs.writeFile 로 전체를 한 번에 씁니다(폴더가 없으면 mkdir recursive).
- 저장 후 다시 읽어 U+FFFD 0개, 한자(\u4E00-\u9FFF) 0개, 앞머리 정상 닫힘, 빈 필수 필드 없음을 검사하고 문제가 있으면 고쳐 다시 씁니다.
