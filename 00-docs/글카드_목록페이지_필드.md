# 글 카드 · 목록 페이지 필드 정의

모든 목록(메뉴별, 도시별, 검색 결과, 관련 글)이 같은 글 카드 컴포넌트를 씁니다.
표의 예시 값은 형식 설명용 가상 값이며, 실제 가격·시간은 게시 전에 확인해서 채웁니다.

## 1. 글 데이터 필드 (글 1건 = 레코드 1건)

### 1-1. 공통 필수

| 필드명 | 타입 | 예시 | 규칙 |
|---|---|---|---|
| id | 문자열 | osaka-3n4d-family | 영문 소문자, 하이픈, 변경 금지 |
| title | 문자열 | 오사카 3박 4일 가족 일정 | 40자 이내 |
| summary | 문자열 | 난바 숙소 기준, USJ 하루 포함 | 60자 이내, 카드에 노출 |
| menu | 선택 | 준비/지역/일정/이동/현장/도구 | 1개만 지정 (원본 위치) |
| type | 선택 | 가이드/도시허브/일정/비교/도구 | 갱신 주기 결정 |
| region | 다중 선택 | 오사카 | 도시 단위, 전국 공통이면 "전체" |
| last_checked | 날짜 | 2026-10-22 | 없으면 게시 불가 |
| published | 날짜 | 2026-10-22 | |
| status | 선택 | 초안/검수/게시/갱신필요 | |
| thumbnail | 이미지 경로 | /img/osaka-3n4d.jpg | 16:9, alt 필수 |
| slug | 문자열 | osaka-3n4d-family | URL용 |

### 1-2. 카드 표시 필드 (여행 판단용)

## 2. 글 카드 레이아웃

### 모바일 (1열)

```
┌─────────────────────────────┐
│ [썸네일 16:9]               │
│ 일정 · 오사카               │  메뉴 · 지역
│ 오사카 3박 4일 가족 일정    │  title
│ 난바 숙소 기준, USJ 하루 포함│  summary
│ [3박4일][자녀동반][테마파크]│  칩
│ 아이 적합 ●●● | 예약 필수   │
│ 1인 OO~OO만원 | 8분         │
│ 확인 2026-10-22             │
└─────────────────────────────┘
```

### 데스크톱 (3열 그리드), 같은 요소를 세로로 배치

카드 표시 우선순위 (공간이 좁을 때 아래부터 숨김)
1. title, summary, last_checked
2. duration, companions
3. kid_fit, reservation
4. est_cost, read_time
5. themes, rain_ok

한 카드에 칩은 최대 3개, 아이콘은 최대 2개만 보이게 합니다.

## 3. 목록 페이지 공통 구조

```
┌ 헤더 / 브레드크럼
├ 페이지 제목 + 설명 (1~2줄) + 글 개수
├ 필터 바 (스티키)       [지역][일수][동행][예산][테마][속성]
├ 선택된 필터 칩 + [초기화]
├ 정렬                    [추천순][최신 확인순][예산 낮은순][읽는 시간 짧은순]
├ 카드 그리드             (모바일 1열, 태블릿 2열, 데스크톱 3열)
├ 더 보기 / 페이지네이션  (12개 단위)
├ 빈 결과 안내            "조건에 맞는 글이 없습니다" + 필터 완화 제안 + 인기 글 3개
└ 푸터
```

## 4. 필터 정의

| 필터 | 값 | 선택 방식 | 대응 필드 |
|---|---|---|---|
| 지역 | 오사카, 후쿠오카, 도쿄, 구마모토, 마쓰야마, 전체 | 다중 | region |
| 일수 | 2박3일, 3박4일, 4박5일, 5박6일 이상 | 단일 | duration |
| 동행 | 자녀(초등), 자녀(중등), 성인, 부모님, 혼자 | 다중 | companions |
| 예산 | 50만 이하, 50~80만, 80~120만, 120만 이상 (1인 총액) | 단일 | est_cost |
| 테마 | 먹거리, 쇼핑, 온천, 테마파크, 휴식, 문화 | 다중 | themes |
| 속성 | 예약 필요, 우천 가능, 아이 적합 높음 | 다중 | reservation, rain_ok, kid_fit |

규칙
- 같은 필터 안의 값은 OR, 필터끼리는 AND입니다.
- 필터 상태는 URL 쿼리로 유지합니다. 예: /itineraries/?region=osaka&duration=3n4d
- 메뉴별로 기본 노출 필터가 다릅니다 (아래 5번).

## 5. 메뉴별 목록 페이지 설정

| 목록 | 기본 정렬 | 기본 노출 필터 | 카드에서 강조 |
|---|---|---|---|
| 준비 /prepare/ | 단계(타임라인)순 | 속성, 지역 | last_checked, read_time |
| 지역 /regions/ | 지역 권역순 | 테마, 동행 | kid_fit, themes |
| 일정 /itineraries/ | 추천순 | 일수, 동행, 지역, 예산 | duration, companions, est_cost |
| 이동 /transport/ | 도시별 | 지역, 속성 | last_checked, est_cost |
| 현장 /onsite/ | 최신 확인순 | 지역, 테마, 속성 | reservation, kid_fit |
| 도구 /tools/ | 인기순 | 없음 | 아이콘, 한 줄 설명 |

## 7. 게시 전 검증 게이트

1. 필수 필드 11개가 모두 채워졌는가
2. last_checked가 게시일 이전 90일 이내인가
3. est_cost에 cost_basis가 같이 있는가
4. 모든 글에 hub 또는 다음 단계 링크가 최소 1개 있는가
5. 같은 글이 두 메뉴에 중복 등록되지 않았는가 (menu는 1개)
6. 썸네일 alt, 요약 60자 이내

## 8. 갱신 규칙

| type | last_checked 경과 | 처리 |
|---|---|---|
| 제도·가이드 | 90일 | status를 갱신필요로 변경, 카드에 배지 |
| 비교·가격 | 90일 | 같은 처리 |
| 도시허브 | 180일 | 같은 처리 |
| 일정 | 365일 | 같은 처리 |
