# 후쿠오카 4박 5일 가족 일정

성인 2명과 초등 자녀 1명 가족 기준 4박 5일 예시입니다. [후쿠오카 3박 4일 가족 일정](/itineraries/fukuoka-3n4d-family/)에 하루를 더해, 4일차에 '노코노시마 섬 반나절' 또는 '과학관과 동물원 시내 하루' 중 하나를 고릅니다. 1~2일차는 2박 3일 글과 같고, 3일차는 해변공원과 마린월드(야나가와 뱃놀이로 바꾸는 방법은 3박 4일 글 참고)입니다. 하루 방문지는 2~3곳, 오후에는 숙소 휴식입니다. 엔화 환산은 100엔 837.70원(2026-10-21, 환율노트) 기준 약 값입니다.

## 어떤 4일차를 고를까
| 구분 | 선택 C. 노코노시마 반나절 | 선택 D. 과학관과 동물원 |
|---|---|---|
| 한 줄 요약 | 배로 10분 가는 꽃 공원 섬, 오전에 가서 점심 전후에 돌아옴 | 시내에서 이동이 짧은 실내외 혼합 하루 |
| 쉬는 날 | 연중무휴 | 동식물원 월요일, 과학관 화요일 휴관이라 같은 날에 둘 다 열려 있는 요일이 한정됨 (아래 표 참고) |
| 날씨 | 바람과 비에 약함. 배가 결항될 수 있어 당일 운항 확인 | 과학관은 실내, 동물원은 우천 시 어려움 |
| 이런 가족에게 | 꽃과 바다 풍경, 배 타기를 좋아함 | 아이가 과학과 동물을 좋아하고 이동을 줄이고 싶음 |

과학관과 동물원은 쉬는 요일이 월요일과 화요일로 달라서, 같은 날에 가려면 수요일~일요일에 해야 합니다 (각 시설 공식). 선택 D는 오전에 동물원, 점심 후 과학관 순서를 추천합니다. 아이가 지쳤다면 과학관만 가도 됩니다.

### 1일차 흐름 (도착일)
- 오전 도착 후 국제선 터미널에서 무료 셔틀로 국내선 터미널로 이동, 지하철로 하카타역까지 약 5분, 요금 260엔 (하카타역 안내 사이트, 비공식).
- 숙소에 짐을 맡기고 점심은 하카타 라멘 (동네 가게 700~1,000엔대, 비공식 정리).
- 오후에 앙팡맨 어린이 박물관. 나카스카와바타역과 건물 안으로 연결됩니다. 10:00~17:00, 마지막 입장 16:00, 1세 이상 2,000~2,200엔 (앙팡맨 공식). 유모차는 박물관 안에 들일 수 없으니 아기띠가 있으면 편합니다.
- 저녁은 나카스 야타이. 대부분 18:30~19:00에 열고 자정 무렵 닫으며 현금 위주, 화장실이 없습니다 (후쿠오카 시 관광 공식). 아이와는 문 열자마자 가는 편이 대기가 짧습니다.

### 2일차 흐름 (다자이후)
- 지하철로 텐진역(하카타에서 5분, 210엔, 재팬 가이드)에 가서 니시테츠 후쿠오카(텐진) 역에서 산책 티켓을 삽니다. 어른 1,040엔, 어린이 600엔 (종이, 니시테츠 공식). 자동 개찰구는 쓸 수 없고 역무원에게 보여줘야 합니다.
- 후츠카이치에서 다자이후선으로 갈아타 합계 약 30분 (다자이후텐만구 공식).
- 텐만구는 입장 무료. 폐문은 계절별로 18:30~19:30, 부속 박물관 마지막 입장은 16:00 (다자이후텐만구 공식).
- 참배길에서 우메가에모치 교환권을 씁니다 (산책 티켓에 포함, 니시테츠 공식). 점심 후 14:30쯤 숙소로 돌아옵니다.

### 3일차 흐름 (해변공원과 마린월드)
- 하카타역에서 JR로 가시이역에서 환승해 우미노나카미치역으로 갑니다. 대기 포함 약 30~44분 (비공식 정리, 마린월드 공식은 가시이선 20분).
- 마린월드는 보통 9:30~17:30, 12~2월 10:00~17:00, 입장은 폐관 1시간 전까지입니다. 성인 2,500엔, 소중학생 1,200엔 (마린월드 공식). 유모차 무료 대여(보증금 500엔)와 수유실이 있습니다.
- 해변공원 입장료는 15세 이상 450엔, 중학생 이하 무료이며 현금만 받습니다 (공원 공식). 2026년 10월 25일은 무료 개원일입니다 (공원 공식).
- 15:30쯤 숙소로 돌아가 쉽니다. 야나가와 뱃놀이로 바꾸려면 3박 4일 글의 선택 B를 참고하세요.

### 4일차 선택 C. 노코노시마 반나절
1. 아침 8시 30분쯤 숙소를 나와 지하철 공항선으로 메이노하마역에 갑니다. 하카타역에서 소요시간과 요금은 확인 필요.
2. 메이노하마역 북쪽 출구에서 버스로 도선장까지 약 15분 (비공식 안내, 확인 필요).
3. 메이노하마 도선장 출발은 낮에 매시 15분입니다. 능고 도선장 출발은 매시 정각이며 마지막 편은 22:45입니다(일요일과 공휴일은 05:00편과 22:45편 운휴, 시 도선 운항표 공식). 오전 9:15 또는 10:15 배를 추천합니다. 배 요금은 가족 편도 어른 230엔 x 2 + 어린이 120엔 = 580엔, 왕복 1,160엔 (시 도선 운임표 공식).
4. 능고 도선장에서 섬 버스(약 13분)로 공원에 갑니다. 3인 왕복 1,300엔 (비공식 안내).
5. 공원 입장료 가족 합계 3,800엔(어른 1,500엔 x 2 + 초등 800엔). 계절 꽃밭, 놀이 시설, 동물 체험이 있고 섬 상점은 현금이 편합니다 (관광 안내 사이트, 비공식).
6. 14:00 또는 15:00 정각 배로 돌아옵니다. 주말과 꽃 행사일은 돌아오는 배가 붐비니 돌아오는 시각을 먼저 정하세요. 숙소 휴식은 16:00부터입니다.
7. 배는 시간당 1편 안팎이라 한 편을 놓치면 한 시간을 기다립니다. 당일 운항 정보는 시 도선 운항표 위의 안내 링크로 확인하세요 (시 도선 운임표 공식).

### 4일차 선택 D. 과학관과 동물원
- 오전: 후쿠오카 시 동식물원. 어른 600엔, 중학생 이하 무료, 9:00~17:00, 입장은 16:30까지 (동식물원 공식). 언덕이 많아 오전에 걷고, 월요일은 쉽니다.
- 점심 후: 후쿠오카 시 과학관. 지하철 나나쿠마선 롯폰마쓰역 3번 출구에서 가깝습니다 (후쿠오카 관광 공식). 5층 기본 전시실은 어른 510엔, 소중학생 200엔 (과학관 공식). 6층 돔 극장(플라네타륨)은 같은 요금이며 상영 일정은 공식 사이트에서 확인합니다. 매표소는 3층이고 신용카드, 교통 IC 카드, 간편 결제를 받습니다 (과학관 공식). 화요일은 쉽니다.
- 동식물원에서 롯폰마쓰까지의 이동 경로와 시간은 확인 필요. 아이가 지쳤다면 과학관만 하는 편이 낫습니다.
- 2026년 10월 25일(일)은 동식물원 무료 개원일입니다 (동식물원 공식).

## 총비용 예시
가족 3인(성인 2, 초등 1) 합계. 3일차는 해변공원과 마린월드, 4일차는 선택 C와 선택 D를 나란히 적습니다.

| 항목 | 선택 C 금액 | 선택 D 금액 | 기준 |
|---|---|---|---|
| 항공 | 약 54~105만원 | 약 54~105만원 | 1인 왕복 약 18~35만원, 위탁수하물 별도. 2026-09~10월 검색 사이트 표시 범위 (카약, 호텔스컴바인). 어린이 운임은 같다고 가정 |
| 숙박 | 약 28~72만원 | 약 28~72만원 | 4박, 방 1개, 1박 약 7~18만원. 가정치, 3인실은 확인 필요 |
| 식비 | 약 44.0~69.1만원 (52,500~82,500엔) | 같음 | 1인 1일 3,500~5,500엔 가정 x 5일 x 3인. 가정치 |
| 교통 | 약 13.8만원 (16,450엔) | 약 11.7만원 (13,990엔) | 공통 7,390엔 + 3일차 JR 왕복 3,600엔(가정치) = 10,990엔. C는 도선 왕복 1,160엔 + 섬 버스 1,300엔 + 지하철, 버스 3,000엔(가정치) 추가. D는 시내 이동 3,000엔(가정치) 추가 |
| 입장료 | 약 14.2~14.7만원 (16,900~17,500엔) | 약 13.0~13.5만원 (15,520~16,120엔) | 공통 앙팡맨 6,000~6,600엔 + 마린월드와 공원 7,100엔 = 13,100~13,700엔. C는 노코노시마 공원 3,800엔 추가. D는 과학관 5층 1,220엔(510 x 2 + 200) + 동식물원 1,200엔(600 x 2) 추가. 돔 극장을 보면 과학관 칸 1,220엔이 더해짐 |
