# 시내 교통

## 개요
시내 이동은 IC카드 한 장, 1일권 여부, 지도 앱 세 가지만 정하면 대부분 해결됩니다. 이 글은 공식 자료로 확인된 사항만 수치로 적었습니다. 지하철 1일권은 후쿠오카와 오사카를 확인했고 도쿄는 확인 필요로 남겼습니다. 기준일은 2026-10-22입니다.

## 핵심 정보
| 항목 | 확인된 내용 | 출처 |
|---|---|---|
| IC카드 호환 | 도쿄 디즈니 리조트 라인에서 Kitaca, PASMO, Suica, manaca, TOICA, PiTaPa, ICOCA, 하야카켄, nimoca, SUGOCA 사용 가능. 지역 카드가 서로 통한다는 뜻 | 도쿄 디즈니 리조트 공식 |
| 후쿠오카 IC카드 | 후쿠오카시 지하철은 하야카켄 가맹점을 운영 중. 카드 구입·충전 방법은 확인 필요 | 후쿠오카시 지하철 |
| 디즈니 리조트 라인 1회권 | 성인(12세 이상) 300엔, 어린이(11세 이하) 150엔. 6세 미만은 성인 1명당 2명까지 무료, 1세 미만 무료 | 도쿄 디즈니 리조트 공식 |
| 디즈니 리조트 라인 1일권 | 1일 성인 700엔·어린이 350엔, 2일 900엔·450엔, 4일 1,500엔·750엔 | 도쿄 디즈니 리조트 공식 |
| 후쿠오카 지하철 1일권 | 성인 640엔, 소아 320엔. 지하철 전 노선(공항선, 하코자키선, 나나쿠마선) 하루 무제한 | 후쿠오카시 지하철 공식 |
| 오사카 메트로 1일권(엔조이에코카드) | 성인 820엔(토·일·공휴일 620엔), 소아 310엔. 오사카 메트로와 오사카 시티버스 하루 무제한 | 오사카 메트로 공식 |
| 도쿄 지하철권 | 가격과 적용 범위 확인 필요 (도쿄 메트로 공식 페이지 접속 실패) | 도쿄 메트로 공식 |
| 공항 안내 앱·경로 검색 | 하네다공항 공식 앱(HANEDA Navigator)에서 항공편·시설 검색과 길 안내 가능. 간사이공항은 공식 사이트에서 경로 검색 서비스로 연결 | 하네다공항, 간사이공항 공식 |

## 선택 기준
- IC카드: 철도·버스·편의점 결제까지 쓰는 기본 도구입니다. 한 장으로 여러 도시를 돌 수 있지만, 어린이용 카드·환불 규정은 JR 각사 공식 페이지에 접속하지 못해 확인하지 못했습니다.
- 1일권: 하루에 정해진 횟수 이상 타야 이득입니다. 예를 들어 디즈니 리조트 라인은 1회 300엔이라 1일권 700엔은 세 번 이상 탈 때부터 이득입니다 (도쿄 디즈니 리조트 공식 요금 기준 계산).
- 지도 앱: 열차 환승과 막차 확인에 쓰되, 개정된 시간표는 반드시 운영사 공식 페이지에서 한 번 더 확인하세요.

## 자주 하는 실수
- 어린이 요금 나이를 한 가지로 생각하는 것: 디즈니 리조트 라인은 12세 이상이 성인이지만, JR 패스는 6~11세가 어린이입니다. 철도 회사마다 다릅니다.
- 1일권 본전 계산을 안 하는 것: 이동 횟수가 적은 날에는 IC카드로 한 번씩 내는 편이 쌀 수 있습니다.
- 앱 하나만 믿는 것: 막차나 운휴는 운영사 공식 안내를 확인하세요.
