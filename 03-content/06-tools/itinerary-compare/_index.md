# 일정 비교표

## 2. 비용을 비교할 때 주의

- 오사카 글은 숙박과 식비를 뺀 값이고, 후쿠오카 글은 항공, 숙박, 식비, 교통, 입장료를 모두 넣은 값입니다. 두 도시의 숫자를 바로 비교하면 안 됩니다.
- 도쿄는 항공을 뺀 3인 합계이고, 구마모토와 마쓰야마도 3인 합계입니다. 1인 값이 아닙니다.
- 숙박, 식비, 항공은 대부분 가정치입니다. 각 글의 계산 기준 항목을 확인하세요.
- 같은 기준으로 비교하려면 [예산 계산기](../budget-calculator/_index.md)의 입력표에 도시별 값을 넣어 보세요.

## 3. 고르는 법

| 상황 | 추천 |
|---|---|
| 일정이 짧고 이동 부담을 줄이고 싶다 | 후쿠오카 2박 3일 (공항에서 시내까지 지하철이 가까움) |
| 테마파크가 꼭 필요하다 | 오사카 2박 3일 또는 3박 4일 (USJ 하루 포함) |
| 도시 + 근교를 한 번에 | 오사카 4박 5일 (교토 하루) |
| 선택지가 많은 대도시 | 도쿄 3박 4일 (예약 필수 시설 확인) |
| 자연과 렌터카 | 구마모토 3박 4일 (지진 이후 현황 확인 필수) |
| 천천히, 온천 중심 | 마쓰야마 3박 4일 느린 일정 |
