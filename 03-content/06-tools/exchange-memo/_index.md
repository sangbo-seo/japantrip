# 환율·엔화 메모

현지에서 가격표를 보고 바로 원화 감각을 잡기 위한 빠른 환산표입니다. 기준일 2026-10-22.

## 1. 기준 환율

이 사이트의 글은 아래 기준을 썼습니다. 환율은 매일 바뀌므로 출발 직전과 환전 날 다시 확인하세요.

| 사용처 | 기준 | 환율 |
|---|---|---|
| 오사카 글 | 2026-10-21 | 100엔 = 약 840원 |
| 후쿠오카 글 | 2026-10-21 | 100엔 = 837.70원 |
| 도쿄 글 | 2026-10-21 (서울외국환중개 매매기준율) | 100엔 = 837.81원 |
| 구마모토, 마쓰야마 글 | 2026-10-16 고시 (한국수출입은행 매매기준율) | 100엔 = 853.02원 |

## 2. 빠른 환산 (1엔 = 약 8.4원으로 계산)

| 엔화 | 원화 |
|---|---|
| 100엔 | 약 840원 |
| 300엔 | 약 2,520원 |
| 500엔 | 약 4,200원 |
| 1,000엔 | 약 8,400원 |
| 2,000엔 | 약 16,800원 |
| 5,000엔 | 약 42,000원 |
| 10,000엔 | 약 84,000원 |
| 30,000엔 | 약 252,000원 |
| 50,000엔 | 약 420,000원 |
| 100,000엔 | 약 840,000원 |

계산 요령은 "엔 x 8.4"입니다. 머릿속으로는 엔에 8을 곱한 값에 그 값의 5%를 더하면 됩니다.

실제 결제 금액은 매매기준율이 아니라 환전 우대율, 카드사 환율, 해외 이용 수수료에 따라 달라집니다. 이 표는 감각용입니다.

## 4. 환전과 결제 팁

- 현금은 숙소 체크인, 작은 식당, 일부 신사 입장료처럼 카드가 안 되는 곳을 기준으로 정합니다.
- 카드는 원화 결제(DCC)를 거절하고 엔화로 결제하는 편이 일반적으로 유리하다고 알려져 있습니다. 카드별 정책은 카드사 안내를 확인하세요.
- 쇼핑 환급은 세금 포함 결제 후 받으므로 현금 흐름이 전보다 길어집니다.
