# 음식

## 개요
가족 여행의 식사는 줄 서기, 아이 메뉴, 알레르기 세 가지가 핵심입니다. 이 글은 일본정부관광국(JNTO)과 소비자청의 공식 자료로 확인된 예절과 표기 규정만 적었습니다. 가격과 영업 정보는 가게마다 달라 확인 필요입니다. 기준일은 2026-10-22입니다.

## 핵심 정보
| 항목 | 확인된 내용 | 출처 |
|---|---|---|
| 자리 안내 | 입구에서 먼저 인원을 알리고 안내를 기다리는 것이 일반적. 인기 가게는 번호표를 뽑는 경우도 있음 | JNTO |
| 직원 호출 | 호출 벨이 있으면 누르고, 없으면 "스미마센"이라고 부름 | JNTO |
| 주문 변경 | 메뉴 변경에 엄격한 가게가 많음. 알레르기는 예외적으로 대응하며 미리 알리는 것이 좋음 | JNTO |
| 팁 | 관습이 없음 | JNTO |
| 이자카야 기본 안주 | 자리에 앉으면 자동으로 나오는 기본 안주(오토시)가 자릿세 역할. 심야 추가 요금이 붙는 곳도 있음 | JNTO |
| 걸어 다니며 먹기 | 상황에 따라 다름. 사람이 많은 곳에서는 흘리기 쉬운 음식과 뚜껑 없는 음료를 피하고 비켜서 먹기 | JNTO |
| 포장 식품 알레르기 표기 | 포장된 가공식품에는 특정 원재료 표시가 의무. 캐슈넛이 특정 원재료로 옮겨진 개정이 있었고 2026년 4월판 안내서가 나옴 | 소비자청 |
| 외식 알레르기 정보 | 식당의 정보 제공 현황을 소비자청이 조사 중(2026-09-30 시작). 가게마다 다르므로 직접 확인 | 소비자청 |
| 아이 메뉴, 예약 방법, 가격대 | 확인 필요 | - |

## 끼니별 선택 기준
- 아침: 호텔 조식, 편의점, 근처 카페 중에서 아이 컨디션에 맞춰 고르세요. 영업 시간은 확인 필요입니다.
- 점심: 대기 줄이 짧은 시간대를 노리거나 백화점 식당가를 고려하세요. 혼잡 시간대는 확인 필요입니다.
- 저녁: 인기 식당은 예약이 필요할 수 있습니다. 예약 방법은 가게별로 확인 필요입니다.
- 편의점: 역과 편의점에는 쓰레기통이 있는 경우가 많습니다 (JNTO).

## 자주 하는 실수
- 알레르기를 주문 후에 알리는 것: 자리에 앉기 전, 가능하면 예약 단계에서 알리세요.
- 포장 식품 표기 규정을 외식에도 그대로 적용하는 것: 식당은 가게마다 다릅니다.
- 이자카야에서 기본 안주 요금을 모르는 것: 자리에 앉으면 자동으로 나옵니다.
- 아이를 데리고 걸으며 먹이는 것: 흘리거나 부딪힐 수 있는 곳에서는 비켜서 먹이세요.
